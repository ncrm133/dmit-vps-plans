## 三网优化到底在优化哪三段路

中国大陆三家运营商各有普通线路和精品线路。普通线路晚高峰拥堵、绕路、丢包是常态，精品线路在骨干网层面做了优先级调度，延迟更低、抖动更小。商家同时接入三家精品线路，让电信走电信的、联通走联通的、移动走移动的，才叫三网优化。

- **CN2 GIA（AS4809）**：中国电信精品承载网。普通 163 线路晚高峰常在 80–150ms，GIA 能压到 60–80ms，丢包率明显下降。GIA 是 GT 的升级版，骨干网优先级更高。
- **AS9929 / CUII**：中国联通精品线路，对标 CN2 GIA。普通联通线路是 AS4837，晚高峰差距明显。
- **CMIN2（AS58807）**：中国移动 CMI 精品线路。移动用户走 CMIN2 比走普通 CMNET 延迟低 10–20ms，晚高峰优势更大。

有资料把“三家去程都走精品线路”单独称作三网双向优化，那是这一品类里最贵的一档。判断一台机器是不是真三网优化，别看商家首页的宣传语，看 traceroute 的回程。

## 晚高峰跑得动吗：第三方实测的速度与延迟

第三方测评给出的洛杉矶三网实测下载速度普遍在 600–800 Mbps 区间，上传在 400 Mbps 以上；1Gbps 端口的 WEE 能跑到 800Mbps 已属理想状态，STARTER 及以上的 10Gbps 端口在流量充足的场景下能轻松跑满。这些是第三方测评口径，不是官网 SLA。

延迟方面，第三方整理的参考值是香港机房到国内 20–50ms，洛杉矶 150–180ms，晚高峰丢包率低。洛杉矶这个数字和普通 163 线路到美西的 150–200ms 差距不算夸张，CN2 GIA 的价值主要体现在晚高峰不塌方，而不是把物理距离抹掉。

## 端口 1Gbps、4Gbps、10Gbps 差在哪

国内家宽普遍在 100–1000Mbps，1Gbps 端口对个人用户不会是瓶颈。4Gbps 和 10Gbps 的端口要跑满，需要你这一端有对应的出口带宽，实际场景是多用户并发、大文件中转、视频分发这类业务。

端口规格和月流量是两件事。STARTER 的 10Gbps 端口配 3000GB 月流量，按满速跑一小时就是 4.5TB，流量会在几天内耗尽。选套餐时先看流量够不够，再看端口是否匹配业务形态。跑个人代理、建站、轻量 API，1Gbps 到 2Gbps 完全够用；做下载站、多租户转发，再看 10Gbps。

## 买之前的 24 小时验机清单

机器开通后按这个顺序过一遍，任何一项明显不达标就在退款窗口内处理。

1. **验回程路由**：用 `besttrace` 或 `nexttrace` 分别 traceroute 到电信、联通、移动的测试 IP，确认回程确实走 CN2 GIA（AS4809）、AS9929、CMIN2（AS58807），而不是 163 或 AS4837 普通线路。这一步决定你买的是不是你以为的那条线。
2. **晚高峰压测**：21:00 到 23:00 之间用 iperf3 对国内节点测速。这是检验三网优化含金量的时间点，白天跑出来的数字没有参考价值。
3. **CPU 跑分对照**：Geekbench 6 跑一轮，和同型号的正常分数比。明显偏低说明宿主机可能超售。
4. **IP 解锁检测**：用 `region-check` 或 `nf` 脚本查 ChatGPT、Netflix、YouTube Premium 的解锁情况。DMIT 的 IP 是随机分配的，不同实例结果不一样，别默认能解锁。
5. **决定去留**：退款窗口是 3 天、流量不超过 30GB，比很多商家的 24 小时宽松，但也别拖到第四天。
